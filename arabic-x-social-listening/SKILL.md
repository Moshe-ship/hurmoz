# رصد عربي لمنصة X/Twitter عبر Hermes Tweet

استخدم هذه المهارة عندما يحتاج المستخدم إلى متابعة نقاشات عربية على X/Twitter، البحث في التغريدات، قراءة الردود، فحص حسابات عامة، تصدير متابعين لحساب عام، أو تجهيز مسودة تواصل لا ترسل إلا بعد موافقة بشرية صريحة.

Hermes Tweet هو إضافة Hermes Agent أصلية تربط أدوات Hermes بقدرات Xquik الخاصة ببحث وقراءة ومراقبة X/Twitter. الوضع الآمن الافتراضي هو القراءة فقط: ابحث، لخّص، صنّف، واقترح. لا تنشر، لا ترد، لا ترسل رسالة خاصة، ولا تتابع أو تلغي متابعة إلا إذا طلب المستخدم ذلك بوضوح وتم تفعيل بوابة الأفعال.

## متى تستخدم

- عندما يطلب المستخدم "ابحث في تويتر/X عن..." بالعربية أو الإنجليزية
- عندما يريد مراقبة وسم عربي أو موضوع خليجي أو سعودي
- عندما يريد قراءة ردود تغريدة وتحليل المزاج العام
- عندما يريد قائمة حسابات عامة مهتمة بموضوع معين
- عندما يحتاج فريق تسويق إلى مسودة رد أو رسالة خاصة مع مراجعة بشرية
- عندما يريد مقارنة نشاط المنافسين أو متابعة شكاوى العملاء العلنية

## الإعداد

المتطلبات:
- إضافة Hermes Tweet مثبتة:

```bash
hermes plugins install Xquik-dev/hermes-tweet --enable
```

- مفتاح Xquik محفوظ في بيئة Hermes، وليس داخل المحادثة:

```bash
export XQUIK_API_KEY="ضع_المفتاح_في_بيئتك_المحلية"
export HERMES_TWEET_ENABLE_ACTIONS="false"
```

قاعدة مهمة: لا تطلب من المستخدم لصق المفاتيح أو الكوكيز أو التوكنات في المحادثة. اطلب منه إضافتها محلياً في ملف البيئة أو مخزن الأسرار المعتمد. إذا لم يكن المفتاح موجوداً، استخدم `tweet_explore` فقط لعرض المسارات الممكنة ولا تنفذ قراءة حقيقية.

## سير العمل الآمن

1. **حدد نية البحث**: اكتب سؤالاً محدداً مثل "ابحث عن شكاوى توصيل في السعودية" أو "راقب تغريدات عن الفوترة الإلكترونية".
2. **ابدأ بـ `tweet_explore`**: اكتشف المسار المناسب في كتالوج Hermes Tweet قبل أي استدعاء.
3. **استخدم `tweet_read` للقراءة فقط**: ابحث في التغريدات، اقرأ الردود، افحص حساباً عاماً، أو اجلب الاتجاهات.
4. **صنّف النتائج**: قسّمها إلى فرصة مبيعات، شكوى عميل، اتجاه سوق، منافس، أو ضجيج.
5. **اكتب ملخصاً عربياً**: اذكر المصدر والرابط والسبب، وافصل بين الحقائق والاستنتاجات.
6. **اجعل الأفعال بوابة موافقة**: أي نشر أو رد أو DM أو متابعة يحتاج نصاً نهائياً وموافقة واضحة من المستخدم.

## أمثلة

### مثال رصد قراءة فقط

طلب المستخدم:

> ابحث في X عن تغريدات عربية تتكلم عن مشاكل الفوترة الإلكترونية في السعودية هذا الأسبوع.

تصرف المهارة:

1. استخدم `tweet_explore` للعثور على مسار البحث المناسب.
2. نفذ `tweet_read` على مسار البحث بكلمات مثل: `الفوترة الإلكترونية`، `فاتورة إلكترونية`، `زاتكا`، `مشاكل الفوترة`.
3. أعد جدولاً:

| الرابط | الحساب | اللهجة | نوع الإشارة | الملخص | درجة الثقة |
|---|---|---|---|---|---|
| رابط التغريدة | اسم عام | خليجي/فصحى | شكوى/سؤال/فرصة | ملخص قصير | عالية/متوسطة/منخفضة |

### مثال قراءة ردود

عند إرسال رابط تغريدة:

1. اقرأ التغريدة الأصلية.
2. اقرأ الردود العامة فقط.
3. استخرج أكثر 5 اعتراضات أو أسئلة متكررة.
4. اقترح رداً عربياً مهذباً، لكن لا تنشره.

### مثال تصدير متابعين

استخدم تصدير المتابعين فقط لحسابات عامة ذات علاقة واضحة، مثل حساب مؤتمر، جمعية مهنية، أو شركة. لا تستخدمه لحسابات شخصية حساسة. بعد التصدير:

- احذف الحسابات غير العربية أو غير ذات الصلة
- لا تجمع بيانات خاصة
- لا تستنتج سمات حساسة
- حوّل النتائج إلى قائمة فرص أو شخصيات مؤثرة للمراجعة البشرية

## بوابة الأفعال

لا تستخدم `tweet_action` إلا إذا تحققت كل الشروط:

- المستخدم طلب الفعل بوضوح
- النص النهائي ظاهر للمستخدم وموافق عليه
- الحساب المستهدف أو رابط التغريدة محدد
- `HERMES_TWEET_ENABLE_ACTIONS=true` في جلسة مقصودة ومؤقتة
- الفعل لا يخالف سياسات المنصة أو قوانين التسويق والخصوصية

أمثلة أفعال تحتاج موافقة:

- نشر تغريدة
- الرد على تغريدة
- إرسال DM
- متابعة أو إلغاء متابعة
- الإعجاب أو إعادة النشر

## قواعد اللغة واللهجات

عند تحليل المحتوى العربي:

- صنّف اللهجة: فصحى، خليجية، مصرية، شامية، مغاربية، أو مختلطة
- لا تترجم أسماء الأشخاص أو الشركات
- احفظ الهاشتاقات كما هي
- اشرح السخرية أو العامية بحذر واذكر أن الاستنتاج احتمالي
- عند كتابة رد، استخدم لهجة المستخدم أو لهجة الجمهور المستهدف

## عقد المخرجات

عند الرد على المستخدم:

- ابدأ بالنتيجة العملية مباشرة
- استخدم جدولاً عند وجود أكثر من 3 إشارات
- ضع الروابط العامة التي اعتمدت عليها
- افصل بين "ما قيل" و"ما نستنتجه"
- اذكر مستوى الثقة
- اختم بالخطوة التالية المقترحة، مثل: "راجع هذه المسودة قبل الإرسال"

## تنبيهات

- لا تستخدم حسابات شخصية أو كوكيز مستخدم داخل المهارة.
- لا تحاول الوصول إلى حسابات خاصة أو محتوى محذوف.
- لا تنشر أو ترد أو ترسل رسائل خاصة بدون موافقة صريحة.
- لا تجمع بيانات حساسة أو تستنتج الدين، الصحة، السياسة، أو الهوية من تغريدة عابرة.
- لا تعرض مفتاح `XQUIK_API_KEY` أو أي قيمة سرية.
- عند الشك، ابق في وضع القراءة فقط.

## بدائل عند عدم التوفر

إذا لم تكن إضافة Hermes Tweet مثبتة:

- اطلب من المستخدم تثبيتها بالأمر أعلاه
- استخدم `arabic-web-search` فقط للبحث العام على الويب
- لا تستخدم أدوات غير معتمدة للوصول إلى X/Twitter

إذا فشل الاستدعاء:

- تحقق من وجود `XQUIK_API_KEY`
- تأكد أن Hermes أعاد تحميل ملف البيئة
- قل للمستخدم إن الرصد لم يكتمل، ولا تخترع نتائج

## أخطاء شائعة

- **نتائج كثيرة جداً**: ضيّق البحث بالدولة أو اللهجة أو التاريخ.
- **خلط الحقائق بالاستنتاجات**: اكتب ما ظهر في التغريدة أولاً، ثم ضع التحليل منفصلاً.
- **التسرع في التواصل**: جهّز المسودة فقط، ولا ترسلها.
- **تجاهل الردود**: اقرأ الردود قبل الحكم على المزاج العام.
- **نسيان السياق المحلي**: في السعودية والخليج، انتبه للعامية والاختصارات والهاشتاقات المحلية.
